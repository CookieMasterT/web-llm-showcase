Choose model format

Weights (q4 or q0)
q4 stores weights in 4 bits, reducing download size and memory use. q0 keeps them unquantized and uses more memory.
Compute format (f16 or f32)
f16 uses 16-bit numbers during generation; f32 uses 32-bit numbers and generally needs more memory.
Examples
q4f16_1-MLC combines 4-bit weights with 16-bit compute. q4f32_1-MLC uses the same weights with 32-bit compute.
